# Chanul Dandeniya - Portfolio

A modern, minimalist portfolio website to showcase my skills, experience, and projects.

## 🚀 Features
- Modern, responsive design
- Smooth animations & interactive elements
- Projects, experience, skills, and contact sections

## 🛠️ Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React icons

## ⚡ Quick Start
```bash
git clone <repository-url>
cd portfolio
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000)

## 🌐 Deployment
